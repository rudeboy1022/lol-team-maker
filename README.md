# LoLカスタム チームメイカー

身内のLeague of Legendsカスタム試合で、10人を5対5に分けるためのツールです。
チームの分け方は次の2つから選べます。

- **ランク基準で自動分け**：ランクと希望ロールをもとに、なるべく公平になるよう自動で分けます
- **リーダードラフト**：リーダー2人が交互にメンバーを指名していきます

決まったチームはボタン1つでコピーして、そのままDiscordに貼れます。

---

## 開き方

`lol-team-maker.html` をダブルクリックすると、ブラウザ（Chrome、Edge、Safariなど）で開きます。
インストールは不要です。

---

## 1. メンバー設定

画面上部の「**メンバー設定**」タブで、参加者を登録します。

### メンバーを登録する

「＋ メンバーを追加」を押すと1行増えるので、次の3つを入力します。

| 項目 | 内容 |
|---|---|
| 名前 | サモナー名や呼び名 |
| ランク | アイアンIV〜チャレンジャーから選択 |
| ロール | TOP / JG / MID / ADC / SUP |

ロールのボタンは、タップするたびに次のように切り替わります。

- **なし**（暗い表示）：やりたくないロール
- **可**（金色の枠）：できるロール
- **メイン**（金色の塗り）：一番やりたいロール

5つ全部を「なし」にした人は **FILL（どこでも可）** として扱われます。

行の右端の「×」で、その人を削除できます。

### 参加者を選ぶ

左端のチェックが入っている人が、今回の参加者です。**ちょうど10人**にチェックを入れてください。
参加人数は画面上部に「参加 10 / 10」のように表示されます。10人のときは緑色になります。

- 「全員の参加を外す」：チェックをすべて外します
- 「ランダムに10人選ぶ」：登録メンバーから10人をランダムに選びます

### まとめて登録する

「まとめて登録 / 書き出し」を開くと、テキストで一度に登録できます。
1行に1人ずつ、`名前, ランク, ロール` の形で書きます。メインのロールには `★` か `*` を付けます。

```
たかし, ゴールド2, MID★ TOP
Yuto, Emerald 4, JG★
みさき, プラチナ1, SUP★ ADC
そうた, シルバー3, FILL
```

- ランクは日本語・英語のどちらでも書けます（例：`ゴールド2`、`Gold II`、`gold 2`）。ディビジョンを省略するとIIになります
- ロールは `TOP` `JG` `MID` `ADC` `SUP` のほか、`トップ` `ジャングル` `ミッド` `ボット` `サポート` なども使えます

ボタンは次の2つがあります。

- 「追加で読み込む」：今のメンバーに追加します
- 「置き換えて読み込む」：今のメンバーを消して入れ替えます

「今のメンバーを書き出す」を押すと、登録中のメンバーが同じ形式のテキストになります。
これをDiscordなどで共有すれば、ほかの人も同じメンバー表を読み込めます。

> 初めて開いたときに表示されているのは、サンプルのメンバーです。
> 「全員削除して自分たちで登録」を押すと消えます。

---

## 2. チーム分け

10人を選んだら、「**チーム分け**」タブ（またはメンバー設定画面の一番下にある「チーム分けへ進む →」）に移ります。
分け方は、パネル上部のタブで切り替えます。

### ランク基準で自動分け

「**チーム分けスタート**」を押すと、BLUEとREDの2チームに分かれます。
各チームの中で、誰がどのロールを担当するかも自動で決まります。

設定は2つあります。

| 設定 | 内容 |
|---|---|
| ロール希望の重視度 | **気にしない**：ランク差だけを見て分けます<br>**標準**：ランク差とロールのバランスを取ります<br>**最優先**：全員が希望ロールに入ることを一番に考えます |
| ランダム性 | **最適のみ**：一番公平な分け方を選びます<br>**少し**：公平な上位数パターンからランダムに選びます<br>**多め**：さらに広い候補からランダムに選びます |

毎回同じチームになるのを避けたいときは、「少し」か「多め」にしてください。

結果画面の見方と操作は次のとおりです。

- **平均レート差**：2チームの平均ランクの差です。100pt がおよそ1ディビジョン分です
- 各メンバーの右側の表示：**メイン**＝第一希望のロール、**可**＝できるロール、**FILL**＝どこでも可の人、**オフロール**＝希望外のロール
- **入れ替え**：BLUEの人とREDの人を1人ずつタップすると、その2人が入れ替わります。ロールは自動で割り振り直されます
- 「**もう一度分ける**」：同じ設定で分け直します
- 決まるまでの演出中に結果の部分をタップすると、演出を飛ばせます

### リーダードラフト

1. 「チームリーダー」で2人を選びます（「ランダムで決める」も使えます）
2. ピック順を選びます
   - **スネーク 1-2-2-2-1**：A → B → B → A → A → B → B → A の順
   - **交互**：A → B → A → B … の順
3. 「**コイントスしてドラフト開始**」を押すと、コイントスで先攻が決まります
4. 手番のリーダーが、残りのメンバーのカードを1人ずつタップして指名します
5. 8人全員が決まると完了です。各チームのロールは希望をもとに自動で割り振られます

- 「1手戻す」「最後のピックを戻す」：直前の指名を取り消します
- 「最初からやり直す」「新しいドラフト」：リーダー選びからやり直します
- 後攻のチームにサイド（BLUE / RED）を選ばせると公平です

---

## 3. Discordに貼る

結果画面の「**Discord用にコピー**」を押して、Discordのチャンネルに貼り付けてください。
次のように表示されます。

```
**カスタム チーム分け**

🟦 **BLUEチーム**　平均 ゴールド II
`TOP` はると（ゴールド III）
`JG ` Yuto（エメラルド IV）
...

🟥 **REDチーム**　平均 ゴールド I
...

平均レート差: 26pt
```

自動でコピーできない環境では、文章が選択された状態になります。その場合は `Ctrl + C`（Macは `⌘ + C`）でコピーしてください。

## その他

### 効果音

画面右上の「効果音 ON / OFF」で切り替えられます。

### データの保存

登録したメンバーと設定は、**使っているブラウザの中に自動で保存**されます。次に開いたときもそのまま残っています。

- 別のパソコンやブラウザで開くと、メンバーは引き継がれません。「今のメンバーを書き出す」で出したテキストを、移した先で「置き換えて読み込む」で読み込んでください
- ブラウザの閲覧データを削除したり、シークレットモードで開いたりすると、保存したデータは消えます。念のため、メンバー表は書き出して控えておくのがおすすめです

### ランクの点数

自動分けでは、ランクを次の点数に置き換えて計算しています。

| ランク | 点数 |
|---|---|
| アイアン IV 〜 I | 0 〜 300 |
| ブロンズ IV 〜 I | 400 〜 700 |
| シルバー IV 〜 I | 800 〜 1100 |
| ゴールド IV 〜 I | 1200 〜 1500 |
| プラチナ IV 〜 I | 1600 〜 1900 |
| エメラルド IV 〜 I | 2000 〜 2300 |
| ダイヤ IV 〜 I | 2400 〜 2700 |
| マスター | 2800 |
| グランドマスター | 3100 |
| チャレンジャー | 3400 |

自動分けでは、「可」のロールに入った人は少しだけ、希望外のロール（オフロール）に入った人は大きく、実力を低めに見積もって計算します。
実際の実力とランクが合わない人（久しぶりの人、サブアカウントの人など）は、体感に合うランクで登録しておくとバランスが良くなります。

### 困ったとき

| 症状 | 対処 |
|---|---|
| 「参加メンバーがちょうど10人必要です」と出る | メンバー設定で、チェックがちょうど10人になるよう調整してください |
| リーダーを選べない | リーダーは参加者（チェックが入っている人）から、別々の2人を選んでください |
| まとめて登録で読めない行がある | `名前, ランク, ロール` の区切りがカンマ（`,` か `、`）になっているか、ランク名が正しいか確認してください |
| 演出が出ない | パソコンやスマホで「視差効果を減らす」など、動きを減らす設定をしていると、演出なしで結果だけが表示されます |
